# 3D 自动立体车库仿真系统

基于 Three.js 的巷道堆垛式立体车库实时仿真，纯前端实现，无需构建。

## 运行

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 功能

- **多层停车架**：4 层 × 6 列 × 巷道两侧，共 48 个车位
- **设备仿真**：横移台车（X）、升降平台（Y）、伸缩货叉（Z + 微升降托举），
  所有运动由带速度/加速度限制的梯形速度曲线逐帧积分驱动，非固定动画
- **入库**：点击「新车入库」，系统自动分配空闲车位（低层、近出入口优先），
  车辆自行驶上平台，经升降 + 横移 + 货叉伸缩送入车位
- **取车**：车辆列表点击「取车」，或直接点击 3D 场景中已占用的车位，执行反向流程
- **实时监控**：设备坐标与运行状态、当前任务步骤、任务队列、总/分层车位占用率、运行日志
- **交互**：鼠标拖动旋转视角、滚轮缩放，支持 0.5x–4x 仿真速度

## 目录结构

```
index.html      页面与仪表盘布局
css/style.css   界面样式
js/config.js    车库尺寸与设备运动参数
js/motion.js    单轴运动控制器（梯形加减速）
js/world.js     3D 场景：货架、堆垛机、车辆模型
js/sim.js       仿真核心：车位分配、出入库任务状态机
js/ui.js        面板数据绑定
js/main.js      渲染主循环
vendor/         Three.js 本地依赖
```
